# Roadmap

## MVP implementado

- [x] Autenticação integrada e páginas privadas.
- [x] Quadros, listas e cartões com persistência no PostgreSQL.
- [x] Movimentação, conclusão, descrição e prazo de cartões.
- [x] Busca, visão de tarefas e dashboard com dados reais.
- [x] Criação de quadro com IA via OpenRouter, quando configurado.
- [x] Testes de interface, API, propriedade dos dados e navegador desktop/mobile.
- [x] Recuperação com token de uso único e hash persistido.

## Evoluções futuras

- [ ] Convites e permissões para colaboração.
- [ ] Checklists, anexos e comentários.
- [ ] Reordenação completa de listas e cartões dentro da mesma lista.
- [ ] Rotinas recorrentes e integrações com agenda.
- [ ] Chat, sugestões e automações adicionais por IA.
- [ ] Infraestrutura compartilhada para rate limiting e múltiplas instâncias.
